# 🚀 InvoiceAI Deployment Guide

Target Niche: **AI Invoice Generator for UK Freelancers**

## 1. Prerequisites
- [Vercel Account](https://vercel.com)
- [Supabase Project](https://supabase.com)
- [Stripe Account](https://stripe.com)

## 2. Environment Variables
Create a `.env.local` file with the following:

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# Stripe
STRIPE_SECRET_KEY=your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your_stripe_pub_key

# AI
OPENAI_API_KEY=your_openai_api_key
```

## 3. Database Setup
1. Go to Supabase SQL Editor.
2. Copy contents of `supabase/schema.sql` and run it.
3. Enable RLS (Row Level Security) and add a policy: `auth.uid() = user_id`.

## 4. Stripe Setup
1. Create a "Pro Plan" product in Stripe Dashboard (£9/mo).
2. Get the `Price ID` and update the checkout route.
3. Set up a Vercel Webhook pointing to `/api/stripe/webhook`.

## 5. Deployment
1. Initialize git: `git init`
2. Push to GitHub.
3. Import to Vercel.
4. Add environment variables.
5. **LIVE!** 🚀
